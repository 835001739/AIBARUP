硬性规定，违反即打回。日志与 API 响应中禁止出现：提示词正文、图片内容、API Key、完整外部 endpoint、本机绝对路径。允许记录 ID、media_type、provider、status、error_code、duration_ms、长度、字节数与尺寸。上传文件只保存受控缓存相对引用如 uploads/<hash>.png。
